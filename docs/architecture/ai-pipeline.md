# Planned AI workflow

The roadmap introduces these stages over several tasks. TASK-001 contains documentation for the workflow.

1. Receive a customer message.
2. Classify the customer's intent.
3. Detect sentiment and urgency.
4. Select relevant company policy.
5. Generate a draft response.
6. Validate the draft.
7. Submit the draft to a support agent for review.

Human review is the approval boundary. Policy selection, provider calls, and validation will need separate tests and failure handling when implemented. See the [AI engineering notes](../ai/README.md).
