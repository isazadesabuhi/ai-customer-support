# Frontend

The Next.js App Router maps the foundation page to `/`. Page and layout files live in `src/app/`. The smoke test renders the page with React Testing Library and jsdom.

Use Node.js 24 LTS and npm 11. From this directory, run `npm ci` to install pinned dependencies and `npm run dev` to start the development server. See the [setup guide](../docs/development/setup.md) for Windows commands, validation, and environment configuration.
